# Changelog

Todas as mudanças relevantes deste projeto serão documentadas aqui.

## [1.0.0] - 2026-11-25

### Adicionado

- Bot Telegram para controle financeiro de MEIs.
- Vendas, maquininhas, boletos, contas, cadastros e anexos.
- Alertas, relatórios e exportações PDF, XLSX e CSV.
- Execução via Docker, documentação operacional e testes de domínio.
