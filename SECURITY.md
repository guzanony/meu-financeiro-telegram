# Política de segurança

## Versões com suporte

Somente a versão mais recente da branch principal recebe correções de segurança.

## Reporte responsável

Não abra uma issue pública para vulnerabilidades, exposição de token, acesso indevido a dados financeiros ou falhas de autorização. Envie uma mensagem privada ao mantenedor do repositório com:

- descrição do problema e impacto;
- passos para reproduzir;
- versão/commit afetado;
- sugestões de mitigação, se houver.

Revogue imediatamente tokens Telegram e credenciais SMTP que possam ter sido expostos. Não inclua segredos no relato.
